## Project Name: BRIDAL GLAM:A Digital Companion for Wedding Beauty and Planning

**BRIDAL GLAM** is a web-based platform designed to help brides plan and manage their complete wedding look by connecting them with curated beauty and styling services. The platform simplifies wedding beauty planning by bringing multiple services and vendors into a single, user-friendly system.


## Features

 **Complete Wedding Beauty Planning**
  - Explore multiple categories such as:
    - Makeup
    - Hairstyles
    - Mehendi
    - Saree Draping
    - Choreography
    - Rental Jewelry

  **Appointment Scheduling**
  - Book beauty and styling services with preferred vendors
  - Select date, time, and service type
  - Track booking status

  **Feedback & Reviews**
  - Brides can submit feedback after service completion
  - Helps improve service quality and vendor credibility

  **Vendor Management**
  - Vendor profiles with portfolios
  - Service details and availability management

  **User Profiles**
  - Secure user registration and login
  - Store preferences and booking history

## Tech Stack

### Frontend
- HTML5  
- CSS3  
- JavaScript  
- Bootstrap (for responsive UI)

### Backend
- Node.js  
- Express.js  

### Database
- MongoDB  

## Backend Functionality

- RESTful APIs built using **Node.js & Express.js**
- Handles:
  - User authentication
  - Vendor profiles
  - Appointment booking
  - Feedback management
- **MongoDB** used for storing:
  - User data
  - Preferences
  - Service bookings
  - Vendor portfolios
